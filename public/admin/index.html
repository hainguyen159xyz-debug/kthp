📌 Quy trình quản lý đơn hàng & chuỗi cung ứng

  1. Khách hàng đặt giày → Hệ thống kiểm tra tồn kho của từng biến thể (Size + Màu).
  2. Nếu còn hàng: Trừ tồn kho ngay lập tức, chuyển trạng thái đơn hàng sang In-Stock (Sẵn sàng đóng gói).
  3. Nếu hết hàng: Đánh dấu Waiting Supplier, hiển thị cảnh báo tại Dashboard để Admin tạo phiếu nhập (Purchase Order).
  4. Khi nhà cung cấp giao hàng tới kho → Admin bấm "Xác nhận nhập kho" → Hệ thống tự động cộng tồn kho và chuyển đơn hàng sang đóng gói giao khách.
